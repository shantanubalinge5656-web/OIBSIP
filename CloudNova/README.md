🚀 Task 1 - Landing Page

Project: CloudNova

CloudNova is a modern, responsive landing page designed for a fictional Cloud & DevOps platform.

The project focuses on creating a polished user interface using only HTML5 and CSS3, with responsive layouts and clean visual design.

Features

- Sticky navigation bar
- Responsive hero section
- Call-to-action buttons
- Cloud/DevOps feature cards
- About section
- Platform statistics
- Customer testimonials
- Call-to-action section
- Footer with contact and social links
- Responsive design for mobile, tablet, and desktop
- CSS hover effects and transitions
- No JavaScript required

Technologies

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries

Run Locally

Clone the repository:

git clone https://github.com/YOUR-USERNAME/OIBSIP.git

Navigate to the Task 1 folder:

cd OIBSIP/Task1-Landing-Page

Start a local server:

python -m http.server 8000

Open in your browser:

http://localhost:8000
