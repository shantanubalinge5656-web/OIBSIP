# TASK 2: Personal Portfolio

**Repository Name:** OIBSIP  
**Task Folder:** WebDev-L1-Portfolio  
**Project Name:** Developer Personal Portfolio Website  
**Author:** Shantanu Balinge  

---

## Description
A modern, responsive, and clean personal portfolio website built as **Task 2 (Level 1)** for the **OASIS Infobyte Web Development & Designing Internship**. The portfolio serves as an interactive showcase of Information Technology academic background, web development skills, OASIS Infobyte internship projects, the **CropX** agricultural project, light/dark theme switching, and real-time contact validation, reflecting an ambitious goal toward **Full-Stack Web Development**.

---

## Technologies Used
* **HTML5**: Semantic elements, ARIA attributes, structured layout.
* **CSS3**: CSS Custom Properties (Variables), Flexbox, CSS Grid, Glassmorphic styling, animations, and mobile media queries.
* **JavaScript (ES6+)**: Dynamic typewriter effect, theme switching, mobile navbar toggle, project category filtering, scroll event handlers, and form validation.
* **FontAwesome 6.5**: Vector iconography.
* **Google Fonts**: Inter, Plus Jakarta Sans, and Fira Code.

---

## Features Implemented
1. **Sticky Header & Mobile Menu Drawer**: Smooth scrolling navigation with hamburger toggle for small screens.
2. **Theme Switcher (Dark/Light Mode)**: User preference toggling saved in `localStorage`.
3. **Hero Section**:
   - Welcome status indicator.
   - Dynamic typing animation cycling through roles ("Aspiring Full-Stack Developer", "Information Technology Student", etc.).
   - Interactive developer code visual card & floating tech badges.
   - Social link icons and call-to-action buttons.
4. **About Me Section**: Information Technology student profile, bio highlighting Full-Stack development aspirations, and key academic/internship highlights.
5. **Skills & Tech Stack**: Categorized skill cards (Frontend Development, IT & Programming Fundamentals, Tools & Workflow) with percentage progress indicators.
6. **Projects Showcase**: Direct showcase of genuine projects:
   - **CloudNova Landing Page** (OASIS Task 1)
   - **Developer Personal Portfolio Website** (OASIS Task 2)
   - **CropX - Smart Agriculture Platform** (Agricultural Tech Project)
7. **Experience & Education Timeline**: Vertical timeline detailing Information Technology education and OASIS Infobyte internship experience.
8. **Interactive Contact Form**: Real-time validation for required inputs (Name, Email format, Message) with instant submission feedback.
9. **Back-to-Top Button**: Smooth floating return-to-top button appearing on page scroll.
10. **100% Responsive Design**: Optimized across mobile, tablet, laptop, and desktop screen sizes.
