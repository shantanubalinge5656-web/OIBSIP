## 📌 Project Overview
This project is an interactive, modern, and fully responsive developer portfolio built using HTML5, CSS3, and JavaScript by an **Information Technology** student aspiring to become a **Full-Stack Web Developer**. It highlights technical skills, OASIS Infobyte internship tasks, the **CropX** smart agriculture project, education timeline, and contact information with sleek dark/light mode UI customization.

## ✨ Key Features
- 🌓 **Dark & Light Mode Switcher**: Toggle themes seamlessly with preference persisted in `localStorage`.
- ⌨️ **Dynamic Typewriter Animation**: Cycles through developer roles in the hero section ("Aspiring Full-Stack Developer", etc.).
- 📱 **Fully Responsive Layout**: Built with Flexbox, CSS Grid, and media queries for desktop, tablet, and mobile displays.
- 🏷️ **Projects Showcase**: Showcases OASIS Infobyte Task 1 (CloudNova Landing Page), Task 2 (Developer Personal Portfolio), and the **CropX** smart agriculture platform.
- 📊 **Animated Skill Progress Bars**: Clean visual representation of technical skills across Frontend, IT Fundamentals, and Tools.
- 📝 **Contact Form Validation**: Interactive form with real-time field validation and success notifications.
- ⬆️ **Scroll to Top Button**: Floating quick scroll navigation button.

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Navigate to the `WebDev-L1-Portfolio` folder.
3. Open `index.html` in any web browser (Chrome, Edge, Firefox, Safari, VS Code Live Server).
